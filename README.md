# a-s-omics

Code and analysis for *Spatial Modeling of Tissues for Morphogenic Field Analysis*
(Osgood-Zimmerman & Raredon), PLOS ONE, PONE-D-26-04349.

The paper adapts geospatial hierarchical models to spatialomics data: it fits a continuous
spatial field with quantified uncertainty to the raw counts of each of 912 ligand and
receptor genes across one field of view from a mouse embryo section, convolves those into
1,477 inferred ligand-receptor interaction fields, and clusters the resulting
high-dimensional set without dimensionality reduction.

## Layout

```
Supplements for Publication/code/    the published pipeline, documented for reproduction
  spatial-modeling/                    preprocessing, model fitting, convolution
  omics-analysis/                      feature selection, clustering, figure scripts
  environment/                         captured sessionInfo()
code-spatial-smoothing/              working tree
  raw-counts/                          the working copy of the spatial-modeling scripts
  controls/                            the manuscript's controls, separately documented
data-inputs/                         inputs, mostly untracked (large)
data-outputs/                        model outputs, untracked (large)
Submission_PLOSOne/submission-2/     the current revision: manuscript, letter, figures
```

Large derived objects are not tracked. Every untracked object is regenerated by a tracked
script, and the READMEs above name which one; where a generating script did not survive, they
say so rather than implying the artifact is reproducible.

## Data

The raw data are public: Chen et al. 2022 Stereo-seq mouse embryo (MOSTA), section E16.5_E1S3,
at <https://db.cngb.org/data_resources/project/CNP0001543>.

Derived outputs are archived as the manuscript's S1 through S8 Files, currently on FigShare.
`Submission_PLOSOne/submission-2/supporting-information/README-supporting-information.md`
has the inventory and links.
