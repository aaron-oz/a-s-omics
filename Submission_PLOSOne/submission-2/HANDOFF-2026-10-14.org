* The pivot, and the decisions already taken

AOZ and Sam decided on 2026-10-14 to make uncertainty the centre of the paper: Sam's view is
that the uncertainty is what is new against the state of the art. The aim is to show places
where signaling fields (and gene fields) look different but are not credibly different given
the uncertainty, and places where they look alike but are, using areal averages, 1D slices,
and whole fields. Signaling fields (common-minimum convolutions) are the primary target; one
gene-field example as well.

AOZ's rulings, 2026-10-14 (do not re-ask):

1. Full pivot; domains and pairing material shrink to a shorter section plus SI.
2. Regions: a few fixed boxes plus a few published anatomical regions (MOSTA annotation,
   =code-spatial-smoothing/controls/e16-fov-annotation.csv=). Never our own domains.
3. Compare on the rate scale (=lambda=, expected count per UMI), not expected counts.
4. Both same-field and cross-field comparisons. Cross-field comparisons are made on shape:
   rate first, then each field divided by its own spatial average within each posterior draw
   (explained in the plan).
5. Joint inference primary, via excursion sets (R package =excursions=); pointwise secondary.
   Installing =excursions= into the =emacs-r= container's user R library is fine.
6. "Looks alike but differs" is always reported with the size of the difference.
7. The systematic run goes on klone.
8. Signaling fields primary, one gene-field example.

* Pitfalls

- *Test the method, not a cheaper cousin.* Write the fidelity table (Phase 3 of the plan)
  before refitting, and check each refit reproduces the saved medians before using its draws.
- *Regions frozen before results* (Phase 2). Do not choose examples after seeing which are
  dramatic.
- *Average of a minimum is not the minimum of averages*: regional signaling summaries need
  bin-level draws of both partners.
- *Clustering software:* reported clustering uses Seurat only; the RcppHNSW substitute gives
  non-comparable numbers. (Not central to the pivot, but the domain section still uses it.)
- *Klone frugality is a hard rule*: measure one task, size to MaxRSS x 2, prefer =ckpt= with
  =--requeue=, throttle arrays, one CPU per single-threaded task. klone needs AOZ to run
  =ssh hyak= (Duo); =ControlPersist 4h= then lets you submit; test with
  =ssh -o BatchMode=yes hyak echo ok=. No R module on klone: =module load apptainer/1.1.5=,
  then =apptainer exec --env R_LIBS_USER=$HOME/Rlib-ctrlB $HOME/containers/geospatial.sif Rscript ...=.
- *Local R:* =OMP_NUM_THREADS=1 distrobox enter emacs-r -- Rscript ...=; never more than half
  the 16 cores.
